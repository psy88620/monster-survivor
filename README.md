# 몬스터 서바이버 (가제) — M5: 최종 보스 균열의 왕 · 영구 강화 · LAN 협동(최대 4명) · 던전 4곳 · 기술 24종

3D 오픈월드 + 2D 도트 몬스터 서바이버. 브라우저에서 실행합니다.

## 웹에서 바로 하기
- https://psy88620.github.io/monster-survivor/ (혼자 하기만. LAN 협동은 아래처럼 `start.bat`으로 실행)

## 실행
- `start.bat` 더블클릭 (Node.js 필요) → 브라우저가 http://localhost:8080 을 엽니다.
- 같은 네트워크의 다른 PC는 서버 창에 표시되는 주소로 접속합니다.

## 한 판의 흐름 (40분)
- 필드보스 → 열쇠 → 속성 던전 4곳. 30:00 예고, 던전 4곳을 모두 정복하거나 35:00가 되면 중앙 평지에 균열이 열립니다(가운데에서 E).
- 균열의 심연 최종 보스 **균열의 왕**: 12초마다 불→얼음→나무→암석으로 형상이 바뀌고(약점 속성 1.5배), 체력 70%·35%에서 보호막 — 균열 수정 4개를 부숴야 합니다.
- 40:00까지 쓰러뜨리지 못하면 왕이 필드로 직접 나옵니다. 쓰러뜨리면 승리.

## 영구 진행 (이 브라우저에 저장)
- 판이 끝나면 균열 조각: 생존 1분당 2 · 처치 100당 1 · 던전 15 · 필드보스 5 · 균열의 왕 60. 도감에 새 몬스터 등록 시 +3.
- 💎 영구 강화: 체력 · 피해 · 이동 속도 · 경험치 · 흡수 범위 · 포획 확률.
- 던전을 한 번 정복하면 그 속성의 두 번째 시작 몬스터 해금(구미화염 · 눈보라마법사 · 카멜레온왕 · 해골티라노).
- 도감: 보스 9종 격파 기록, 몬스터별 서식지 · 처치 수.

## 같이 하기 (LAN, 최대 4명)
1. 한 PC에서 `start.bat` 실행 (처음에 Windows 방화벽 창이 뜨면 '허용'. 다른 PC가 못 들어오면 8080 포트 허용 필요)
2. 친구 PC에서 몬스터 고르기 화면 아래에 나오는 주소(예: `http://10.x.x.x:8080`)로 접속
3. 모두 몬스터를 고르면 함께 시작합니다. 아무도 없으면 고르는 즉시 혼자 시작합니다.
- 각자 자기 몬스터·기술·동료·경험치·레벨. 구슬은 주운 사람 것이고, 누가 기술을 고르는 중이어도 게임은 계속됩니다(혼자일 때만 멈춤).
- 쓰러지면 친구가 곁에 3초 서 있으면 일어납니다. 전멸하면 "바로 재시작"(모두 누르면 같은 몬스터로 다시) 또는 "대기실로". 던전은 누가 E를 누르든 모두 함께 들어갑니다.
- 인원이 늘면 몬스터 수·체력과 보스 체력이 늘어납니다.
- 방식: 모든 PC가 같은 시드로 같은 게임을 계산하고, 서버는 1/60초마다 모두의 입력을 모아 나눠 줍니다(lockstep).
  그래서 게임 로직의 난수는 `rng.js`의 `rand()`만 써야 합니다. 화면 효과·소리·던전 장식은 `Math.random` 사용.

## 조작
WASD 이동 · 왼쪽 클릭 고유기(마우스 위치 조준) · Shift 대시 · Q 필살기 · 오른쪽 드래그 시점 회전 · 휠 확대/축소 · E 던전 입장/퇴장 · F 동료 지켜(마우스 위치) · R 동료 따라와 · B 가벼운 모드(빛 번짐·그림자·풀 끔, 느린 PC는 자동 전환) · M 소리 · N 피해 숫자 켜기/끄기 · Esc 일시정지 · 레벨업 1/2/3

## 구조
- `server.js` 정적 파일 서버 + 협동 로비와 입력 중계(직접 구현한 WebSocket, 의존성 없음)
- `public/js/net.js` 서버 연결(로비·입력 묶음 수신) · `public/js/rng.js` 게임 로직용 시드 난수
- `public/js/world.js` 지형(600m, 6개 지역), 소품 배치, 충돌, 미니맵
- `public/js/sprites.js` 도트 몬스터 빌보드(인스턴싱)
- `public/js/game.js` 플레이어(여럿)·적·기술·경험치·레벨업. 플레이어별 상태는 player 객체에 있고 `game.player`는 지금 계산 중인 플레이어
- `public/js/data.js` 속성 상성, 몬스터, 지역별 출현표, 기술
- `public/js/main.js` 카메라·입력·HUD·메뉴
- `public/js/party.js` 포획한 동료(최대 3, 지켜/따라와, 기절 후 회복)
- `public/js/dungeon.js` 필드보스 4종과 던전 4곳(DEFS): 얼음 쌍둥이 빙하룡 · 불 용광로 수호룡(밸브) · 나무 천년 고목 정령(뿌리) · 암석 고대 골렘(돌기둥)
- `public/js/skills.js` 속성별 자동 기술 24종(불·얼음·나무·암석 각 6)
- `public/js/fx.js` 파티클·빛 번짐용 효과 · `public/js/dmgnum.js` 피해 숫자(내 공격만, 적마다 0.3초 합산, 최대 60개, 상성 색)
- `public/js/ambience.js` 바람에 흔들리는 풀(플레이어 주변 30m), 물결, 구름 그림자, 해 그림자, 지역별 안개·입자
- `public/js/audio.js` 효과음 · `public/js/dex.js` 도감(브라우저에 저장) · `public/js/meta.js` 균열 조각 · 영구 강화 · 해금
